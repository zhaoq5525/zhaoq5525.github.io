arp流程

发表于 2026-09-18 更新于 2026-09-28 分类于 计算机网络
ARP 广播限局域网；跨网只 ARP 网关；代理 ARP 是路由器代答，不是广播跑过路由器。

我们分两大阶段：

  • 阶段 1：主机开机 → 获取 IP 地址

  • 阶段 2：拿到 IP 后，要和网关通信

阶段1 - 获取 IP 地址

获取IP地址有两种方式：DHCP 和 静态手动配置。

方式A： DHCP 分配地址

  1. 电脑开机后网卡启动（此时没有 IP、子网掩码、网关）
  2. 主机发送 DHCP Discover（二层广播）索要 IP 地址
  3. DHCP 服务器收到广播后，回复 DHCP Offer 提供可用 IP 、子网掩码、网关地址、DNS
  4. 主机回复 DHCP Request 进行确认
  5. HCP 服务器回复 DHCP Ack 确认分配。

拿到 IP 之后，操作系统会自动生成本机路由表： 规则：目标 IP 和我在同一个网段 → 直接局域网发包； 目标 IP不在本网段 → 数据包全部发给默认网关。

方式B：手动配置地址

直接在网卡设置里手动输入 IP、掩码、网关，跳过 DHCP 四步。

阶段2：ARP 完整流程

网卡收发数据，二层帧必须填目标 MAC，不知道 MAC 就发不出包 → 这就是 ARP 要解决的事

完整 4 步标准 ARP 流程

假设：

  • 你的电脑：192.168.8.1 MAC：MAC-A
  • 目标主机：192.168.8.254 MAC：MAC-B（就是你 arp 表里面那条网关）

① 检查本地 ARP 缓存表

你的主机先看内存里的 ARP 表（就是 arp -a 看到的那张表）如下：

如果表里已经有 192.168.8.254 对应的 MAC：直接拿这个 MAC 封装数据包，不用 ARP 请求

如果没有记录 / 记录过期 / 你执行了 arp -d \* 清空缓存 → 触发 ARP 请求

② ARP 请求包（广播！发给局域网所有人）

你的电脑在局域网广播：

“谁的 IP 是 192.168.8.254？如果是你，请把你的 MAC 地址发给我！ 我的 IP：192.168.8.1，我的 MAC：MAC-A”

目标 MAC 写：ff-ff-ff-ff-ff-ff （全 F 广播 MAC，局域网所有网卡都会接收这个帧）

广播：同一个局域网内所有电脑都收到这条消息，但是 IP 不匹配的主机会直接丢弃这个 ARP 请求，不回复

③ ARP 应答包（单播！只回复给发起请求的主机）

192.168.8.254 收到广播，发现 IP 就是自己，于是回复一个 ARP 应答：

“我就是 192.168.8.254，我的 MAC 是 MAC-B”

⚠️ 应答不是广播，是单播，直接发给你的电脑 MAC-A，别的主机收不到这个回复

④ 更新 ARP 缓存表

你的电脑收到 ARP 应答，把 192.168.8.254 + MAC-B 写入本机 ARP 缓存表 类型标记为动态（会超时自动删除，默认 Windows 动态 ARP 条目 10 分钟左右老化）

之后一段时间内，再访问 192.168.8.254，直接查表，不再发 ARP 广播
