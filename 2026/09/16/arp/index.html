ARP - Address Resolution Protocol 地址解析协议

发表于 2026-09-16 更新于 2026-09-18 分类于 计算机网络 ， 网络协议
用于存储IP地址和MAC地址的映射关系

在局域网中，当主机或其它三层网络设备有数据要发送给另一台主机或三层网络设备时，需要知道对方的网络层地址（即IP地址）。

三层网络设备：路由器、三层交换机

但是仅有IP地址是不够的，因为IP报文必须封装成帧才能通过物理网络发送，因此发送方还需要知道接收方的物理地址（即MAC地址），这就需要一个通过IP地址获取物理地址的协议，以完成从IP地址到MAC地址的映射。

ARP 地址解析协议，即可实现将IP地址解析为MAC地址。

IP 地址的存在性

我的理解： mac地址是物理上的标识，IP 虽然也是标识，但是 IP 本身还具有能够构建组织的属性，这是一种逻辑的组织架构。

用mac来进行沟通意味着庞大的调度能力，这就意味着 设备A→设备A3 的中途需要经过一些完全无关的通讯对象，而 IP 的逻辑组织架构就直接从 设备A→设备A2→设备A3 不需要其他无关的单位来进行工作。

如上图所示，左侧是我理解的使用mac地址方式来进行通讯时发生的场景，由于没有所谓的组织架构所以相当于是各找各的，而右侧是使用 IP 地址方式来进行通讯的场景，不会存在mac地址那种没有组织的处境。

ARP - 逻辑地址与物理地址共同使用的粘合剂

实现将 IP 地址解析为 MAC 地址。

**我的理解：**IP 地址组织能力固然很好，但是却做不到mac地址的唯一标识功能，ip 能从逻辑上找到对应的对象，mac能让你确认这个对象。

这样看，ip 地址 和 mac 地址就都是必须的呢，前者提供效率后者提供身份上的确定。

既是如此，那么就需要有一种途径将 IP 和 mac 共存，arp 的产生也就因此知道了，arp 让主机的逻辑地址和物理地址都能同时在使用层面共同推进。

ARP（Address Resolution Protocol，地址解析协议）是一种将 IP 地址解析为 MAC 地址的协议；设备通过维护「ARP 表（ARP Cache）」来记录 IP 与 MAC 的映射关系，ARP 的工作结果就体现在这张 ARP 表中。
