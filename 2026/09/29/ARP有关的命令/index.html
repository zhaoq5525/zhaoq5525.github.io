ARP有关的命令

发表于 2026-09-29 分类于 计算机网络
Windows 和 Linux 的 arp 表都存储在内核内存里面，
  无论是动态arp 还是 静态arp 都是存储在内存中，重启就会消失。

Windows 和 Linux 的 arp 表都存储在内核内存里面。

Linux 中的 arp 属于 Linux 内核「邻居子系统」的数据结构，放在内核 RAM，没有固定的文本文件保存整张arp表。

可以看内核的虚拟文件接口（只是内核内存的映射，不是硬盘文件）

Windows 也没有持久保存 ARP 动态条目的地方。

Windows

arp

接口: 192.168.8.1 — 0x9

Internet 地址 物理地址 类型 说明
192.168.8.254 00-50-56-f5-34-d9 动态 网关。动态 ARP 条目：你之前 ARP 广播拿到网关 MAC。访问外网 / 跨网段时，二层帧目的 MAC 填这个。
192.168.8.255 ff-ff-ff-ff-ff-ff 静态 本网段广播地址，MAC 全 F，二层广播

动态 (dynamic)：ARP 广播询问得到，有老化时间，超时会删除，需要重新 ARP 请求。

静态 (static)：系统预先内置，不是 ARP 报文学习的，不会老化。这里的组播、广播条目全部属于系统内置静态，不是 ARP 协议学习的主机条目。

Windows 网络栈初始化网卡的时候，自动把这些固定的 IP→组播 / 广播 MAC 映射预先写到 ARP 缓存表。这些映射是协议标准写死的，是固定数学换算关系；内核直接内置，不是 ARP 报文学习得到，所以 Windows 归类标记为静态。

广播地址 192.168.8.255、255.255.255.255，二层目的 MAC 固定就是ff-ff-ff-ff-ff-ff，协议规定死，不需要 ARP 解析。

IPv4 组播地址（224.0.0.0~239.255.255.255） IPv4 组播 IP 按照标准算法，直接算出对应的二层组播 MAC（01-00-5e开头）。

公式：组播 MAC 前缀固定01:00:5e，后面 24bit 取组播 IP 低 23 位。 内核不需要发 ARP 包去询问，直接计算就能得到 MAC。 所以 Windows 直接预置这一条，类型标记静态。

Linux

ip neigh

lladdr = link-layer address，就是 MAC 地址

REACHABLE：可达的，最近一段时间内，内核收到过来自这个 IP 的确认，这个 IP-MAC 映射是有效、可信，发包的时候可以直接使用这个 MAC，不需要重新发 ARP 请求

STALE：陈旧的，IP-MAC 映射条目还保存在表里，但是已经超时，不再确认对方是否在线，条目还没删除，只是可信度下降，当你再次要发包给 192.168.8.2时： 内核不会直接用这个 MAC，会先发送 ARP 探测（邻居请求），验证 MAC 是否还正确，收到应答 → 变回REACHABLE，无应答 → 标记INCOMPLETE，多次失败后删除该条目。

状态 含义
REACHABLE 可达，近期验证有效
STALE 陈旧，信息可能失效，下次发包前校验
INCOMPLETE ARP 请求已发出，还没收到应答
PROBE 正在主动发探测包验证
FAILED 探测失败，无法解析 MAC
PERMANENT 永久静态 ARP，永不老化

手动创建一条 arp 条目

创建一条 arp 条目，ip 地址 192.168.8.254，mac 地址 00:50:56-ea-59-71，这条 IP‑MAC 映射，归属到 ens160 网卡的邻居表：

邻居表-neighbour table

主机的以外的都属于是邻居，记录邻居信息的表自然就叫做邻居表，arp表就是一种类型的邻居表，准确的说是邻居表的一个部分。

ARP 表是邻居表的子集；邻居表是更大的统称，包含 ARP（IPv4）和 NDP（IPv6）两类邻居记录。

IPv4 邻居：靠 ARP 喊话拿到信息 → 这部分内容，就是我们常说的ARP 表，IPv6 邻居：不靠 ARP，靠 NDP（邻居发现协议）拿到信息 → 这部分不能叫 ARP 表

Linux 内核设计这本通讯录的时候，是一本通用本子，IPv4、IPv6 的邻居记录都写在同一个表结构里。

总结

Windows 只是把 REACHABLE、STALE 合并统称为「动态」，不展示中间状态。

Linux不仅区分条目会不会老化，动态条目还额外记录这条 IP-MAC 映射是否经过最近验证（REACHABLE/STALE）。

Windows 和 Linux 的 arp 表都存储在内核内存里面，由于这个缘故，所以如果事前不编写对应的程序那么重启后相关的信息就会消失。
